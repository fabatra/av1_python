📖 Resumo Teórico: Estruturas Fundamentais em Python

Confira os principais conceitos utilizados para programar a lógica do robô e do compilador:

  • Entrada e Saída (input / print): Captura a digitação do usuário e exibe mensagens na tela.
  • Tomada de Decisão (if / elif / else): Permite que o programa escolha caminhos com base em condições numéricas.
  • Laço Contínuo e Parada (while True e break): Cria um ciclo de execução contínuo até que a interrupção de emergência seja acionada.
  • Tratamento de Falhas (try...except ValueError): Impede o travamento do robô ao tratar erros de conversão de dados.
  • Sequência de Fibonacci: Padrão rítmico (1, 1, 2, 3, 5) aplicado na Campainha Acessível para Surdos.

📌 EXEMPLO RESOLVIDO PASSO A PASSO

Enunciado Exemplo: Como receber a leitura do sensor e decidir se o carrinho deve parar ou continuar?

# Exemplo de código em Python: distancia = float(input("Digite a distância (cm): ")) if distancia <= 10.0: print("🛑 Obstáculo próximo! Parar motores.") else: print("🟢 Caminho livre! Continuar rodando.")

💡 Lembrete de Sintaxe em Python

• input() ➔ Lê texto do teclado • float() / int() ➔ Converte texto para número • if/elif/else ➔ Decisão por faixas numéricas • while True / break ➔ Repetição contínua e parada • try/except ➔ Tratamento de exceções e erros
