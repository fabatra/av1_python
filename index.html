📖 Resumo Teórico: Estruturas Fundamentais em Python

Confira os principais conceitos utilizados para programar o cérebro dos robôs:

  • Tomada de Decisão (if / elif / else): Permite que o programa escolha um caminho com base em condições numéricas.
  • Módulo random.randint(a, b): Sorteia um número inteiro entre os valores a e b (utilizado para simular variações de sensores ou sorteio de rotas).
  • Laço Contínuo e Interrupção (while True e break): Cria um ciclo de execução contínuo no microcontrolador até que o comando break seja acionado (botão de emergência).
  • Tratamento de Erros (try...except ValueError): Evita que o programa do robô trave se a leitura do sensor for nula, vazia ou inválida.

📌 EXEMPLO RESOLVIDO PASSO A PASSO

Enunciado: Um robô lê a distância de um obstáculo. Se for menor ou igual a 10 cm, ele deve parar. Como estruturar essa condição?

# Exemplo de código em Python: if distancia <= 10: print("🛑 Obstáculo próximo! Parar motores.") else: print("🟢 Caminho livre! Continuar rodando.")

💡 Lembrete de Sintaxe em Python

• if/elif/else ➔ Tomada de decisão por faixas • while True / break ➔ Repetição contínua e parada de emergência • try/except ValueError ➔ Captura e tratamento de falhas • int(input()) ➔ Lê e converte texto para número inteiro
